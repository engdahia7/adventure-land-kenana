# مغامرة أرض الكنانة - سر المخطوطة الفرعونية 🏺

لعبة مغامرات تفاعلية مستوحاة من الحضارة المصرية القديمة، تحتوي على الاستكشاف، الحوارات، الألغاز، جمع الأدلة، والمهام.

## المميزات

- 🗺️ خريطة ومناطق استكشاف
- 📜 نظام قصة وحوارات
- 🧩 ألغاز وتحديات
- 🎒 حقيبة الأدوات والعناصر
- 🔎 نظام الأدلة والتحقيق
- 🏛️ عناصر مستوحاة من الحضارة الفرعونية

## تشغيل المشروع محلياً

المتطلبات:
- Node.js 18 أو أحدث

التثبيت:

```bash
npm install
```

تشغيل وضع التطوير:

```bash
npm run dev
```

بناء نسخة الإنتاج:

```bash
npm run build
```

## إعداد المتغيرات

إذا تم استخدام خدمات الذكاء الاصطناعي، انسخ:

```bash
.env.example
```

إلى:

```bash
.env.local
```

ثم أضف المفاتيح المطلوبة.
